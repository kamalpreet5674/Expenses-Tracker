# Personal Expense Tracker 💰

A Python CLI based Personal Expense Tracker application.

## About Project

This project helps users manage their daily expenses.

Users can:
- Add expenses
- View expenses
- Filter expenses by category
- Generate monthly summaries

## Technologies Used

- Python
- JSON File Handling
- Functions
- Exception Handling
